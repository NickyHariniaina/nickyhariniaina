# Nicky Hariniaina — Portfolio

Personal portfolio for [Nicky Hariniaina](https://nickyhariniaina.github.io/), a backend developer based in Antananarivo, Madagascar.

## Stack

- React 19 + TypeScript (Vite)
- React Router
- Lenis smooth scroll

## Development

```bash
pnpm install
pnpm run dev
```

## Build

```bash
pnpm run build
```

## Deploy

Automatic deploys on [Vercel](https://vercel.com) from the `prod` branch.
